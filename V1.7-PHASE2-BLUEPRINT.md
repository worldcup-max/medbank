# V1.7 Phase 2 — Exam Blueprint — CONTRACT (DOC + tests only; implementation held for approval)

Box: MEGA-QBANK-MASTER-ROADMAP → V1.7 → Phase 2. Content-free (uses the existing pool). Reuses the session runner, exposure logic, session timer, and per-skill/cog analytics. **Do not modify V1.5, A6, A7, or V1.6.**

## §0. Job
Turn Mega from a pool into an **exam simulator**: the student specifies a blueprint (how many questions, what skill/cognitive mix, optional time), and Mega assembles the closest-matching set **from existing questions**, reporting any shortfall. It is a *smarter item selector in front of the existing runner* — nothing more.

## §1. Gap vs today
`_mgCfg` has a single `skill` filter + single `level` filter + `count`. Blueprint adds: skill **distribution** (%), cognitive **distribution** (%), shortfall reporting, and an optional whole-exam timer. No new runner, scheduler, or content.

## §2. Blueprint inputs
- **total question count** (e.g. 10/20/40/60 or custom)
- **skill distribution** — percentages summing to 100 (Diagnosis/Investigation/Management/Complications/Differential/Next-step)
- **cognitive-level distribution** — percentages (interpretation / clinical_reasoning / complex_reasoning / exam_trap)
- **optional whole-exam time** (untimed default)
- **existing-pool-only sourcing** (scope = courses/topics, as today)

## §3. Selection behavior (LOCKED)
- **Deterministic** — same blueprint + same pool ⇒ same selection (stable ordering, no randomness).
- **Respects available inventory** — never selects more of a slice than exists.
- **No duplicate questions** in a session.
- **No cross-Target identity changes** — selection is read-only on questions; each keeps its own `target_id`.
- **No changes to A6/A7; no new scheduler; no generation** — every selected item ∈ the existing pool.
- **Skill distribution is authoritative**; cognitive mix is filled best-effort within skill slices (spec §8).

## §4. Shortfall reporting (LOCKED)
- If a blueprint can't be fully satisfied (e.g. not enough Complications in scope), **tell the student** — show **requested vs available vs delivered** per dimension.
- **Never silently substitute** a different distribution: a slice shortfall delivers fewer items for that slice and is reported; it does **not** backfill from other slices to hit `count`.

## §5. Timer (LOCKED)
Untimed default · optional **whole-exam** clock · **auto-submit at zero** · **no per-question timer**. Reuses the existing session timer (`qbTick`/`startTs`).

## §6. Analytics (LOCKED)
- Record the **requested** blueprint and the **actually delivered** distribution (+ shortfall).
- Preserve all existing per-question / per-Target / per-skill / per-cog analytics unchanged.

## §7. Not in Phase 2
Saved/named blueprints (D3 — deferred). Per-question timing. Integrated/case items (later phases). Any generation.

## §8. THE CRITICAL INVARIANT (explicit acceptance test)
> **A Blueprint changes only WHICH existing questions are selected for the session. It must not change what those questions mean to A6/A7 or create a new retention identity.**

Concretely: if a Blueprint selects 40 questions spanning 12 Targets, A6 still sees the **exact same 12 Target identities** it would have seen outside Blueprint mode. The selector never reads, writes, or derives `target_id`; the set of Targets is simply the union of the chosen questions' own `target_id`s.

## §9. Deterministic acceptance matrix (pure selector `blueprintSelect(pool, blueprint)`)
| # | Case | Expected |
|---|------|----------|
| 1 | determinism | same pool+blueprint ⇒ identical selection |
| 2 | respects inventory | never selects > available in any slice |
| 3 | no duplicates | no `_qh` appears twice |
| 4 | shortfall | under-supplied slice ⇒ reported {requested,available,delivered}; delivered < count; **no backfill from other slices** |
| 5 | **identity invariant** | selected Targets = union of chosen questions' own `target_id`; selector never mutates/creates `target_id` |
| 6 | skill authoritative + cog best-effort | slice counts match skill % (±rounding); cog mix approximated within slices |
| 7 | no generation | selected ⊆ pool |
| 8 | whole-exam timer contract | untimed default; when set, a single session deadline; auto-submit; no per-item clock |
