The same file app.html loads, running against the real scenes/*.json — so the player can be proven without touching the app.

You opened this over file://, so the browser will refuse to fetch the scene JSON. Serve the repo root over HTTP first — e.g. npx serve . or python -m http.server — then open /viz-training/real-mesh-test/player-harness.html.
