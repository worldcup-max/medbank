# Prompt sheet: severe malaria, set 5 (f-child-phc-05)

**Patient:** Amina, a 6-year-old Hausa girl in an orange dress and headscarf. **Hospital:** a small rural primary health care centre in northern Nigeria, with sky-blue and white walls and a neem tree outside.
**What this set teaches:** severe anaemia with dark "cola" urine (blackwater) and deep, fast breathing.

## How to use this sheet

1. Open the Flow project "Nov 17 - 09:26". Set 5 already has pictures there (look for the girl in orange).
2. Every picture has a **name** in bold. When you download a picture, rename the file to exactly that name, for example `base.png` or `exam-eyes.png`.
3. Put all the downloaded files for this set in one folder, for example `Downloads/medbank-set5`. Then tell me in the thread, or upload them there.
4. **Edits:** click the named picture in Flow first (usually `base`), then paste the prompt into the edit box.
5. **New pictures** (arrival and close-ups): attach `base` as the reference, then paste the prompt.
6. If Flow gives you two options, keep the one that looks most like the description. If Flow refuses a prompt, skip that picture and tell me which one. I'll reword it.

Ticked boxes are already made in Flow, so just download them. Unticked boxes still need making.
