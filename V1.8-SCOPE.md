# V1.8 — targeted at the two bottlenecks Production Run #1 exposed

Data-driven, not guessed. Run #1 human review (27 approve / 9 edit / 5 reject) showed the failure classes were:
generator single-best-answer construction (biggest editable bucket) and one real R2 safety miss (#20 duplicate SGLT2i).
V1.8 addresses exactly those two, and nothing else.

## Change 1 — Generator single-best-answer discipline (a17TransformPrompt)
Added: before emitting, test EVERY distractor against the exact facts written; if any stays defensible, add a
disambiguating fact or change the key — never rely on the reader missing a competitor. Plus: never key a redundant
drug (2nd of a class already prescribed) or one contraindicated by the current regimen. Else return {ok:false}.
Targets: #8, #24, #27, #33, #39 (broken-SBA) and prevents #20-type at generation.

## Change 2 — R2 redundant/contraindicated-therapy + mechanism-wording checks (a17ClinicalPrompt)
Added STEP 1c: read current meds + comorbidities; valid=false if the keyed management is redundant (e.g. dapagliflozin
while on empagliflozin, 2nd ACE-I/ARB/beta-blocker) or contraindicated (pioglitazone/verapamil in HFrEF; metformin
"stopped" at eGFR >=30 when guidelines only dose-reduce). Plus a mechanism-wording sanity check.
Targets: #20 (the R2 MISS), #18, #36.
