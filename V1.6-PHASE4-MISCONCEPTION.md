# V1.6 Phase 4 — Misconception intervention — CONTRACT (DOC ONLY — do not build yet)

Box: MEGA-QBANK-MASTER-ROADMAP → V1.6 → Phase 4. Builds on frozen A6/A7 + Phase 1. Reads frozen `smartDiagnose`. **Hardest gate** (misconception is the hardest diagnosis to validate + the only one needing content investment).

## Premise — target the mistaken BELIEF, not the topic
Gap = "I don't know this" → teach. Fragile = "right but unsure" → reinforce. **Misconception = "confidently wrong"** → the student is applying a *wrong rule*. Re-teaching the topic doesn't fix a wrong rule; you must **contrast** it against the correct one.
```
WRONG + CONFIDENT → V1.5 = MISCONCEPTION → V1.6 Phase 4:
   IDENTIFY the likely wrong rule from the CHOSEN distractor (its rationale / trap_type)
   → CONTRAST: "Why B, not D — the key distinction is …" (correct concept vs the wrong rule they used)
   → one DIFFERENT question testing the SAME distinction (from the Target's A6 siblings)
   → DONE
Then A6 (untouched) owns the spaced retest; success = the confident-wrong signature disappears at later assessments.
```

## Wording — LOCKED (soft, never accusatory)
- **Never** tell the student "you have a misconception."
- At-miss line: **"You may be using a misleading rule here,"** then explain the distinction.
- Escalate to **"You seem to be consistently applying X when Y is the better distinction"** ONLY after repeated evidence across sessions. Tutor tone, not a grading machine.

## Surface
- **At-miss** (unlike fragile): fires on the confident-wrong answer, because the intervention needs the **chosen distractor** (which wrong option, captured at that moment). Opt-in prompt: `[Challenge me] / [Keep going]`, default Keep going.
- Also appears in the post-session "3 things to fix" queue, ranked **top** (misconception is actively harmful — Frank's D4 ranking).

## Non-negotiable rules (same spine)
- **V1.6 NEVER touches retention.** No `qbSchedApply`, no `_sched` write. The confident-wrong miss already routed the Target into A6. Phase 4 only contrasts + flags. A6 is sole authority.
- **No second scheduler / no parallel pool.** The follow-up question comes from A6's `qbQuestionsForTarget(target_id, served)` — ideally one testing the same distinction once distractor tagging exists (see content).
- **Identity = `target_id`.**
- **Masking:** any immediate follow-up answer = `misconception_practice`, kept OUT of `_attempts` (same rule as gap/fragile) — a correct challenge answer is not proof the belief is gone.
- Reads frozen `smartDiagnose`; never modifies V1.5/A6/A7. **No AI generation** (A7 supplies retention questions only, via A6).

## Content — the bottleneck (why this is last)
- **v1 (ship-able):** reuse the chosen distractor's existing `rationale` + `trap_type` to build the contrast. No new content.
- **v2 (only if the A/B wins):** distractor-level tagging (each wrong option → the specific wrong rule it encodes) for sharper contrasts. Invest **only** if v1's contrast beats generic re-drill.

## Measurement — the hardest gate
Misconception diagnosis is the hardest to validate, and content is costly, so the bar is highest:
- Group A (generic): confident-wrong → generic re-drill.
- Group B (matched): confident-wrong → contrast.
- Measure later A6 assessments: does B eliminate the **confident-wrong signature** (miscon rate → 0, accuracy up) faster than A? If A ≈ B, **cut Phase 4** — don't invest in distractor tagging.

## Telemetry
`intervention_shown` / `intervention_completed` keyed by `target_id`, `itype:'misconception'`, `intervention_version:'v1.6-phase4'`, plus the chosen-distractor id and `trap_type`. Follow-up answer → durable event `event_type='misconception_practice'`. The signature-disappearance signal is read from the Phase-1 stream (`wrong_confident` → `correct_confident` for the same `target_id`).
