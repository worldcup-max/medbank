# V1.7 — FROZEN. Acquisition playbook.

Status: **VALIDATED & FROZEN.** The pipeline is no longer the bottleneck; source breadth is.
Proven by the 60-pilot: unique-reasoning yield rose cardio_renal ~6→8, **gi_hepatic ~3→8 (2.7×)**, resp_cardiac 6 (control),
and duplicate rejection *fell* as source breadth grew (more independent material → less repeated reasoning). 0 dangerous passes.

## FROZEN — do not change (no more experimentation)
- Reviewer prompts (R1 dependency, R2 clinical validity, R3 single-best/defensible-alternative)
- Severity model + thresholds (`qaVerdict`, hard/major/minor/none)
- R1 integration gate (dependency test)
- Generator (transformer prompt, self-gate, answer-position rebalancer, prefix normalizer)
- Diversity layer + source-aware budget (cap 3)
Any change here reopens calibration. Don't, without NEW evidence.

## The validated recipe (per family)
3–6 concepts/family → multiple independent source questions/concept → ~20–30 useful sources/family.
Author concept lectures (see SOURCE-POOLS-V1.7.md for the pattern), import via Add Lecture → QBank, then transform
from DISTINCT sources (one per source; breadth, not re-mining, is what produces unique yield).

## Production acquisition loop
1. Build source pool (concept lectures) → 2. Transform from distinct sources → 3. R1 integration →
4. R2 clinical validity → 5. R3 defensible-alternative → 6. Diversity/provenance filter → 7. Human review →
8. Approved production QBank. Provenance chain kept throughout: Family → Concept → Source → Candidate → QA → Approval.
