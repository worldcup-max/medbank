## Premise — fragile is LIGHT by design
Gap = "I don't know this" → teach. **Fragile = "I can answer it, but I'm not sure"** → a *light* reinforcement, never a full lesson. Over-remediating fragile **punishes appropriate uncertainty** — explicitly avoid:
```
right + unsure → massive remediation / long lesson / another forced test   ✗ WRONG
```
The intended shape is minimal:
```
RIGHT + UNSURE → V1.5 = FRAGILE → V1.6 Phase 3:
   CONFIRM ("you're getting these right — let's make it stick")
   → brief REINFORCEMENT (reuse existing rationale/teaching/note — NOT a new lesson)
   → OPTIONAL immediate practice (one Target-sibling question, skippable)
   → DONE
Then A6 (untouched) owns the spaced retention check; success = accuracy holds while confidence RISES
   (right+unsure → right+confident) across A6 Target assessments.
```

## Non-negotiable rules (same spine as Phase 2)
- **V1.6 NEVER touches retention.** No `qbSchedApply`, no `_sched` create/advance/reschedule. The original right+unsure attempt already routed the Target into A6 (`'hold'`); Phase 3 only *flags*/reinforces. A6 is sole authority for due date, interval, sibling selection, exhaustion, A7 fallback.
- **No second scheduler / no parallel question pool.** Optional practice draws from A6's `qbQuestionsForTarget(target_id, served)`.
- **Identity = `target_id`.**
- **No AI generation** (A7 supplies retention questions only, via A6).
- **Reinforcement reuses existing assets** (rationale / teaching / objective / note via `q.src`). No new content authored to ship Phase 3.
- **Reads frozen `smartDiagnose`**; does not modify V1.5/A6/A7.
- If any immediate practice runs, it is `fragile_practice` telemetry — **kept out of `_attempts`** (same masking rule as `gap_practice`): a correct immediate practice is not proof of retention.

## UX
- **Primary surface: post-session**, in the "3 things to fix" style — gentle, opt-in ("You're getting these right but aren't sure — quick reinforcement?"). **Not** an at-miss interruption (fragile is a *correct* answer; interrupting a correct answer is wrong).
- Optional single practice, clearly skippable. Default action = done.

## Measurement (the honest gate)
Fragile's value is only proven if **reinforcement makes confidence rise / retention hold better than plain A6 SRS alone.** A6 already brings right+unsure Targets back on its own, so the A/B is:
- Group A (generic): fragile Target → plain A6 retention, no reinforcement.
- Group B (matched): fragile Target → brief reinforcement (+ optional practice) → A6 retention.
- Measure across later A6 Target assessments: does B reach **right+confident** faster / retain better than A? If A ≈ B, **cut Phase 3** — A6 alone suffices.

## Telemetry
`intervention_shown` / `intervention_completed` keyed by `target_id` + `diagnosis_version:"v1.5"` / `intervention_version:"v1.6-phase3"`. Optional practice → durable `gap_practice`-style event with `event_type='fragile_practice'`. The confidence-rise signal is read from the Phase-1 stream (consecutive eligibility events for the same `target_id`: `correct_unsure → correct_confident`).
